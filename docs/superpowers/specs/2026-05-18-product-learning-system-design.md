# Product Learning & Exam System - Design Spec

## Overview

A local web-based learning system for new employees to study 杰冠 (Jieguan) kitchen equipment products. Modeled after 驾校一点通 (driving school quiz app) - users can browse products, practice with quiz questions, take mock exams, and review wrong answers. Includes a password-protected admin panel for content management.

## Pages & Features

### 1. Home Page (首页)
- Navigation bar: 学习中心 | 刷题练习 | 模拟考试 | 错题集
- Subtle "管理" button in top-right corner
- Welcome banner with system description

### 2. Learning Center (学习中心)
- **Filter bar**: 14 series filter buttons + "全部" (show all)
- **Product grid**: 2-3 cards per row
- **Each card displays**:
  - Product image (from images/ folder)
  - Model number (e.g. EOA-101-CMP)
  - Product parameters (Chinese + English translation)
  - Functions & Applications (AI-generated description)
  - English name

### 3. Practice Mode (刷题练习)
- **Question Type 1**: Product image on left → 4 model options on right
- **Question Type 2**: Model number on left → 4 product image options on right
- Instant feedback: green highlight for correct, red + correct answer for wrong
- Can filter by series or practice all
- Wrong answers auto-saved to 错题集

### 4. Mock Exam (模拟考试)
- Random selection of up to 100 questions from all products
- Mix of both question types
- Sequential answering (no going back)
- Final score display (1 point each, max 100)
- Post-exam review of wrong answers
- Wrong answers saved to 错题集

### 5. Wrong Answer Collection (错题集)
- List all previously wrong questions with details
- "重新练习错题" (re-practice wrong answers) button
- "清空错题集" (clear all) button
- Shows error count per question

### 6. Admin Panel (后台管理)
- **Access**: Click "管理" → Enter password `123456`
- **Product table**: View all products in editable table format
- **Add/Edit product**: Form with fields for model, series, image upload, parameters, functions, English name
- **Image upload**: Upload directly in admin, auto-saved to images/ folder
- **AI Function Generator**: Button to auto-generate Functions & Applications based on model/series
- **Export**: Save data to products.json

## Tech Stack

- **Single HTML file** with embedded CSS and JavaScript
- **No frameworks** - vanilla JS for simplicity
- **Data storage**: Embedded default data + localStorage (user edits, progress, wrong answers)
- **Images**: Stored as base64 data URLs in the data layer
- **Offline**: Works completely offline, no server needed
- **Helper script**: `update-data.js` (Node.js) to batch-import images from a folder

## Data Architecture

**Problem**: Browser's `file://` protocol cannot fetch local files (JSON, images) due to security restrictions.

**Solution**: Multi-layer data approach:

1. **Default data**: Embedded directly in `index.html` as JavaScript objects (products with placeholder data)
2. **localStorage layer**: Admin edits, user additions, and wrong answers all stored in browser localStorage
3. **Image handling**:
   - Admin can paste image URL or upload image → stored as base64 in localStorage
   - Helper script `update-data.js` scans `images/` folder, converts to base64, outputs to `data.js`
   - User includes `<script src="data.js">` to load batch-imported images
4. **Data merge on load**: Embedded defaults → merged with localStorage overrides → merged with data.js images

## Data Flow

1. **Initial use**: Open index.html → loads embedded default data → user can browse/quiz
2. **Admin adds product**: Via admin panel → saved to localStorage → immediately visible
3. **Batch image import**: Place images in images/ folder → run `node update-data.js` → generates `data.js` with base64 images
4. **Progress**: Quiz results and wrong answers saved to localStorage
5. **Return visit**: localStorage restores all edits and progress
